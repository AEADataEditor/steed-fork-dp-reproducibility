The full list is presumably in the SI Appendix, which is not in this repo, so no entry comes from the paper.

- *Online*: the README has no usable package link, or a wrong one, so the package was found via the article's journal page.

Every DOI listed was resolved against the DataCite API, and the title/creators shown come from DataCite. The article DOI is DataCite's `IsSupplementTo` link where one exists.
